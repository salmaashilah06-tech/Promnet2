# 🌐 Personal Website – Salma Ashilah

Website ini merupakan **website portofolio pribadi sederhana** yang dibuat sebagai latihan dalam mempelajari dasar-dasar pengembangan web menggunakan **HTML**.

Website ini berisi informasi mengenai profil, data diri, riwayat pendidikan, hobi, project yang pernah dibuat, serta halaman kontak untuk berkomunikasi.

## 📌 Fitur Website

Website terdiri dari beberapa halaman utama:

- **Home** – Menampilkan halaman utama dan perkenalan singkat.
- **About** – Berisi profil, data diri, hobi, dan riwayat pendidikan.
- **Project** – Menampilkan beberapa project yang pernah dibuat beserta teknologi yang digunakan.
- **Contact** – Menyediakan informasi kontak dan form pesan.

## 🚀 Project yang Ditampilkan

Beberapa project yang terdapat dalam website ini antara lain:

1. **Basic Data**
   Membuat sistem bengkel motor menggunakan VS Code, XAMPP, dan MySQL.

2. **Website Westra**
   Membuat rancangan website yang menampilkan berbagai makanan khas Jawa Barat menggunakan Figma.

3. **Game Kreswara Studio**
   Membuat sebuah game sederhana menggunakan bahasa pemrograman Python.

## 🎯 Tujuan Project

Project ini dibuat untuk:

- Mempelajari struktur dasar HTML.
- Memahami penggunaan elemen heading, paragraph, list, table, image, link, dan form.
- Membuat navigasi antarhalaman website.
- Mengenalkan diri dan menampilkan portofolio project.
- Menerapkan dasar penggunaan Git dan GitHub.

## ⚠️ Catatan

Website ini masih menggunakan **HTML tanpa CSS dan JavaScript**. Oleh karena itu, tampilan website masih sederhana dan form kontak belum terhubung dengan server atau database.

Project ini dapat dikembangkan lebih lanjut dengan menambahkan:

- CSS untuk memperbaiki tampilan dan responsivitas.
- JavaScript untuk interaksi website.
- Backend untuk memproses form kontak.
- Database untuk menyimpan pesan dari pengguna.
